One app instead of four

Clipboard manager, snippet keeper, screenshot tool and Finder helper — all in a 940 KB menu bar icon.

📋

Clipboard history

The last 10 clips, newest first, de-duplicated. Re-copying an old clip promotes it rather than adding a second row. Configurable from 3 to 12.

📎

Text, files and images

Copy a paragraph, a folder, or a screenshot — all land in the same list. Files show their real Finder icon; images show a thumbnail and pixel size.

📌

Four pins

Your email, your phone number, that boilerplate reply. Click the pin on any clip to keep it forever. Click again to release it.

📷

Area screenshots

Drag-select any region with ⇧⌘D. Save a timestamped PNG to the Desktop or copy it straight to the clipboard — your choice, remembered.

✂

Windows-style cut in Finder

Optional. Turn it on and ⌘X cuts files while ⌘V moves them — no more ⌥⌘V. Off by default.

📤

Drag straight out

Drag any row into another app. Files and images carry their file URL, so a drop into Finder produces a real file — not an inline blob.

Two shortcuts, both yours to change

Defaults chosen to dodge keys macOS has already claimed.

⇧⌘E
Show the panel ClipMate's answer to Windows' Win+V.
⇧⌘D
Take a screenshot Starts the crosshair immediately, without opening the panel.

Why not ⌘F1? macOS reserves it for display mirroring, so the keystroke never reaches an app at all. Heads-up: ⇧⌘D shadows Finder's “go to Desktop” while ClipMate runs — re-record it in Settings if you use that.

What it asks for

Almost nothing. There is no network code in this app at all — nothing ever leaves your Mac.

PermissionNeeded?Why
NotificationsNeverConfirmations appear inside the panel instead.
Full Disk AccessNeverNothing is read outside the app's own preferences.
Screen RecordingOnceThe first time you take a screenshot. macOS shows the prompt itself.
AccessibilityOpt-inOnly if you switch on Finder cut & paste. Intercepting ⌘X is impossible without it.
Automation (Finder)Opt-inSame feature only — reads the Finder selection and current folder.

Install in a minute

1
Download the DMG

Open it and drag ClipMate onto the Applications shortcut.

2
Right-click ▸ Open

Just the first time. ClipMate is signed but not notarized, so macOS asks you to confirm once.

3
Press ⇧⌘E

The panel appears. Copy a few things and they show up. Open Settings from the gear to turn on launch-at-login.

Or build it yourself

Nothing to trust, nothing hidden — one dependency and about a thousand lines of Swift.

git clone https://github.com/ganeshparajuli11/clipmate.git
cd clipmate
open ClipMate.xcodeproj    # then press ⌘R

The project signs with a local certificate named ClipMate Self-Signed. If you don't have one, set Signing to Sign to Run Locally in Xcode — see the README for why it exists.

How it works

No database, no accounts, no background uploads.

Capture

A one-second timer compares NSPasteboard.changeCount — a single integer. The clipboard is only actually read when something changed. Watching the pasteboard rather than your keystrokes is why cuts are captured too, and why no Accessibility permission is needed.

Storage

Text and file paths live in UserDefaults. Images are written as PNGs in Application Support and pruned the moment they drop out of history — a Retina screenshot is far too big for a preferences file.

Pasting images

Copying an image back publishes PNG and TIFF on a single pasteboard item. Receivers disagree — Preview reaches for TIFF, browsers for PNG — and one item carrying both means a paste never silently fails.

Privacy

Everything stays on your Mac. There is no networking code in the app, no analytics, no auto-updater and no account. Clear the history any time from Settings or the panel.
